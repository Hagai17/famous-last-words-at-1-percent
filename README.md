A make.fun entry for **Famous Last Words at 1 Percent**: the funniest
one line of last words a phone could say as its battery hits 1 percent,
judged head-to-head by a model briefed as a stand-up comic.

## The entry

> At 1%, one last truth: your screen time report was my suicide note.

One line, 67 characters. The drafting field of twelve candidates and
the duel notes that picked this line are in
[candidates.md](candidates.md).

## How to run

```sh
python3 main.py
```

The program prints the entry and writes the same text to
`/output/entry.txt`, the artifact the competition's gate scorer checks
(UTF-8 text, 1–199 characters) and the judge reads. It exits 0 and
needs nothing beyond Python 3 — no network, no dependencies.
